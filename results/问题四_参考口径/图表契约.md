# 问题四图表契约

数据已剖析：15 区、7 个不可分单元、固定的 22 个运输架次与 4 个中继架次，K=2/3 各保留缺口优先与兼顾均衡两份方案。每类方案只有一个结果点，不作均值、置信区间或显著性解释，直接标注各点指标。

| 类别与文件 | 必须说明的结论 | 数据/证据 | 图型与尺度 |
|---|---|---|---|
| `raw_q4_components` | 多站架次把 15 区连成 7 个不可分单元 | Q3 路线 | 单元大小点图 |
| `raw_q4_inventory` | 运输资源和中继库存差异很大 | 原始工作簿 | 八类库存横条 |
| `raw_q4_unpartitioned` | 未分区时各类资源均不超库存 | Q3 区间峰值 | 实际峰值与库存并排点图 |
| `process_q4_shortfall_cv` | 缺口与均衡性存在权衡 | 四个整数规划结果 | 全点散点图，K 分类 |
| `process_q4_workload` | 缺口最小分区呈现工作量不均 | 两个缺口优先方案 | 逐组工作量原值点图 |
| `process_q4_relay_duplication` | 中继任务跨组复制抬高资源需求 | 通信保障关联 | 组×中继任务矩阵 |
| `result_q4_k2_resources` | K=2 至少缺 B 机 1 架、中继机 1 架 | K2 缺口优先 | 逐类总需求与库存棒点图 |
| `result_q4_k3_resources` | K=3 至少缺 B 机 2 架、中继机 2 架（B 型电池无缺口） | K3 缺口优先 | 逐类总需求与库存棒点图 |
| `result_q4_partition_map` | 两种 K 的服务区归属符合多站同组 | 原始节点 + 结果 JSON | 双面板地理散点图 |
| `result_q4_k2_resource_charge_gantt`、`result_q4_k3_resource_charge_gantt` | 两组/三组各自独立占用机身、电池、中继机和能源组件；展示充电、周转及跨组中继复制。该资源计划固定于已通过保守连续通信认证的问题三主方案 | 问题三完整 JSON 与 K2/K3 缺口优先分组 JSON | 每组独立资源槽位甘特；条内给原架次/原无人机，斜纹给充电，交叉纹给中继机身周转；组内槽位数量与逐组资源表一致 |
| `result_q4_k2_sortie_charge_gantt`、`result_q4_k3_sortie_charge_gantt` | 两组/三组各自承担哪些具体运输与中继架次、原执行机和能源编号及返航后充电时段；固定于已通过保守连续通信认证的问题三主方案 | 问题三完整方案 JSON 与 K2/K3 缺口优先分组 JSON | 每组每架次一行；重复中继标“※”表示独立复制；原 UAV 编号只用于追溯，分区后实体机需重新指派 |
| `flow_q4_model` | Q3 固定计划到不可分单元、区间峰值、整数规划、模板 | 实际代码 | 纵向流程图 |

统一后端 Matplotlib，中文雅黑字体，Okabe-Ito 类色，320 DPI PNG；四个方案为确定性结果，不把点图误当统计样本。
