### 3.4 判定词与证据强度

- 判定只能取：**符合**、**偏离**、**无法判定**（后者须给出所需补证据与责任条目）。
- 「符合」的最小证据：一条可复算命令 + 观测值 + 期望值 + 容差来源；只有主张值无独立复算者一律不得判「符合」。
- 「偏离」必须同时给出：偏差量、可能原因、影响范围（是否影响主结论/是否只影响展示精度）。

## 5. 证据格式规范

### 5.1 主格式（审计条目表，逐条一行）

| 列 | 含义 | 要求 |
|---|---|---|
| 条目id | 唯一编号 | `<问题>-<规则id>-<序号>`，例如 `Q3-C41-001` |
| 题面出处 | 权威依据 | `题目原文.txt:行号`（+`含公式:行号`）与式号/规则号；缺一不可 |
| 实现位置 | 代码位置 | `文件:行` 或 `文件:函数名:行`；不允许只写文件名 |
| 独立推导或对拍命令 | 复现/核验命令 | 仓库根可执行；L1 对拍须为**独立实现**（不得复用被测模块的同一函数） |
| 观测值 vs 期望值 | 数值对照 | 两侧均给全精度（≥10 位有效数字）并带单位 |
| 判定 | 结论 | 符合 / 偏离 / 无法判定 |
| 缺陷级别 | 分级 | blocker / high / medium / low（无缺陷填 —） |

### 5.2 六列最小变体（主张对照表，T1 主张逐条核验用）

`主张值 | 复现值 | 来源文件+SHA-256 | 命令 | 环境 | 结论`

- **来源文件+SHA-256**：必须给主张所在文件的 SHA-256（可用 `UAV/results/数值实验复核/实验清单.json` 的 `指纹登记` 字段），以便确认比对的是同一版本（T1 差异 D9/D10 要求此项不可省）。
- **命令**：必须从仓库根出发、只读输入为原始数据；若需重跑生成脚本，须在**隔离工作副本**中执行（见 §7.3）。
- **环境**：Python 版本 + 依赖版本（numpy/scipy/pandas/openpyxl/matplotlib）+ 平台；随机实验须另给 seed 与 iterations。
- **结论**：符合 / 偏离 / 无法判定，并指向对应缺陷级别。

## 6. 缺陷分级与必须判为 blocker 的判据

### 6.1 分级定义

| 级别 | 定义 | 处理要求 |
|---|---|---|
| **blocker** | 使结论**不可验证**或**与题面/附录直接冲突**的缺陷：违反题面硬约束、公式与附录 2/3 不符、判定方向错误、资源可行性检查缺失、结论性质被夸大，或结论依赖的脚本/数据缺失/指纹不符而未说明 | 必须先修复或显式降级结论；修复前该问不得判「通过」 |
| **high** | 影响数值正确性或可复现性，但结论方向仍可能成立（例如参数取值与数据文件不符、容差未声明、审计范围缺项、单一指标超容差但未影响结论） | 修复或给出可接受性论证；须在证据表中显式记录 |
| **medium** | 文档与产物不一致、表述不精确、记录不完整，但不改变数值结论（例如 README 架次数写错、图表契约残留旧口径） | 列入修复清单；不影响「复核完成」判定，但必须在报告中登记 |
| **low** | 措辞、命名、排版、单位书写等不影响判定一致性 | 建议修复；不阻塞 |

### 6.2 必须判为 blocker 的情形（含示例）

| 编号 | blocker 情形 | 示例（本仓库语境） |
|---|---|---|
| B1 | **遗漏题面硬约束** | 问题三未把「爬升/巡航/下降/投送全阶段连续通信」作为硬约束，或把未认证区间不计入通信缺口（违反 C-43/C-41） |
| B2 | **能耗/时间/充电公式与附录 2 不符** | 充电时长漏掉 0.90 拐点或未乘 0.65/0.35（违反 C-27）；飞行时间漏下降段或把爬升/巡航速度混用（违反 C-14）；把下降附加能耗计入（违反 C-17） |
| B3 | **链路门限方向取错或漏双向取 min** | 直连只用 T→G 的 122 dB 与 G→T 的 129 dB 之一而未取 min；或回传用中继接入端参数（20 dBm/6 dBi）而非回传端（19 dBm/8 dBi）（违反 C-36/C-37） |
| B4 | **资源占用区间未按半开区间检查（或不重叠检验缺失）** | 把端点相接 `[a,b)` 与 `[b,c)` 判为重叠；或同一电池任务占用与充电区间未做不重叠校验（违反 C-28） |

### 6.3 必须修复判据（「复核完成」的前置条件）

1. blocker 计数 = 0（或相关结论已被显式降级/撤回，并在报告中说明降级范围）。
2. 文档数字与产物矛盾：要么修正文档，要么在产物旁显式标注旧口径；不得两者并存而无说明。
3. 参数与记录不符（含复现清单指纹、收敛记录规模、脚本默认值与已发布参数）：须重跑并更新记录，或修正记录并说明差异来源。
4. 结论超范围：须改写表述并加入适用范围限定。
5. 脚本不可运行/源码缺失：须修复使可运行，或在报告中声明该步骤不可复现并下调依赖该步骤的结论。
6. 每一条 blocker/high 都必须有可复算命令与最少证据（§5.4）。
