# 问题二改进方案结果说明（四口径对比 / 含路线信息）

> 方法：候选航段池 + 长时自适应大邻域搜索 + 逐机型调度优化（B/C 全排列、A 局部搜索，已应用于发布方案）；全部方案满足 80 箱唯一送达、硬时限零违反、加权延误为零、无人机/电池占用不重叠、返航 SOC ≥ 20%。

> 注：单变量消融（`问题二_改进求解/ablation_3v4.py`）显示 3 站与 4 站同预算最优指标相同，改善来自长时/多起点搜索，4 站容量未生效。

口径定义：时间优先 = 完成时间→能耗→架次；均衡 = 三项归一化和最小；能耗优先 = 能耗→时间→架次；架次优先 = 架次→时间→能耗。
相比原发布方案（25 架次 / 6410.481 s / 69.965 kWh / 硬时限最小余量 204.170 s / SOC 21.866%），时间优先主方案为 **24 架次 / 5903.038 s / 65.891 kWh / 硬时限最小余量 337.293 s / SOC 20.137%**：快 507.442 s（−7.916%）、省 4.073935 kWh（−5.823%）、少 1 架次；**硬时限余量更大，但 SOC 余量更紧**。
