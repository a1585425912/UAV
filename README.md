## 复现

将原始 `数据/` 目录放在仓库根目录，保持原文件名和层级。需要 Python 的 `numpy`、`scipy`、`openpyxl`、`pandas`、`pillow`、`matplotlib`；绘图使用本地 math-modeling Skill 的导出工具和中文字体。按顺序运行：

```bash
python 航路几何数据.py
python 问题一_直接指派整数规划.py --sensitivity
python 问题一_直接指派审计.py
python 问题二_复现.py --iterations 8000 --seeds 0 1 2 3 4
python 问题三四_复现.py
```

问题一求解器会同步生成当前 Q1 工作簿。问题二据此填写 Q2，问题三填写 Q3，问题四填写 Q4。若只核对已发布结果，可分别运行三个独立审计脚本：`问题一_直接指派审计.py`、`问题二_独立审计.py`、`问题三四_独立审计.py`。Q1 的现成数据图保留在仓库中，`问题一_直接指派绘图.py` 重绘其 MILP 过程图和流程图。

本仓库的启发式主方案不声明全局最优；问题四的 MILP 最优性只针对固定的问题三计划。旧方案可从 Git 历史查看，不与当前工作簿混用。
