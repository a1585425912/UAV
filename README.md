## 问题一：统一航段口径结果

## 复算说明

原始题目附件与 DEM 数据未放入本仓库。需将原始 `数据/` 目录置于仓库根目录，保持原文件名和目录层级，然后在 Python 环境中安装 `numpy`、`scipy`、`openpyxl`、`matplotlib` 等依赖。绘图脚本还调用本地的 `~/.codex/skills/math-modeling/tools/figure/scripts/` 工具；使用这些脚本前需安装对应的数学建模 Skill。之后执行：

```bash
python 航路几何数据.py
python 绘制航路直线距离.py
python 绘制爬升下降与地形.py
python 绘制三维地形.py
```

统一航段问题一的复现命令为 `python 问题一_统一航段复现.py`；输入哈希、参数和环境见[本次复现清单](results/问题一_统一航段/复现清单.json)。旧口径的复现记录见[历史复现清单](results/历史结果_旧口径/复现清单.json)。
