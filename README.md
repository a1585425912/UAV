## 问题一：求解方法对比

现有解用“完整枚举货箱子集 + 锚点位掩码 DP”得到。为避免结论依赖单一算法，又做了四种方法的对照实验：

- **直接指派 MILP + 能耗切平面**（精确，不生成子集）：得到同一最优解 18 架次 / 59.130290 kWh / 32,781.508 s。
- **集合覆盖 LP 下界**：16.394444，逐区取整后求和为 18。
- **质量/体积解析下界**：15 个区逐区取整后合计 18，与上界完全闭合。
- **BFD 贪心**：毫秒级得到 18 架次（架次数恰好最优），能耗高 0.410734 kWh（+0.69%），无最优性保证。

规模实验显示：瓶颈是 DP 的 3^n 而非候选枚举的 2^n。n≤17 时枚举 DP 仍可在秒级给出精确解，n≥19 时 DP 在 60 s 内无法完成，而直接指派 MILP 在 n=21 仍只需 2.8 s。

## 复算说明

原始题目附件与 DEM 数据未放入本仓库。需将原始 `数据/` 目录置于仓库根目录，保持原文件名和目录层级，然后在 Python 环境中安装 `numpy`、`scipy`、`openpyxl`、`matplotlib`、`pandas`、`pillow` 等依赖。问题三、四的完整复现命令为 `python 问题三四_复现.py`，依次完成候选点搜索、联合调度、分区 MILP、独立审计、绘图及输入 SHA-256 清单。绘图脚本调用本地的 `~/.codex/skills/math-modeling/tools/figure/scripts/` 工具，并使用微软雅黑字体；在 Windows 上使用前需安装对应的数学建模 Skill。几何数据单独复算可执行：

```bash
python 航路几何数据.py
python 绘制航路直线距离.py
python 绘制爬升下降与地形.py
python 绘制三维地形.py
```

现行问题一依次执行 `python 问题一_直接指派整数规划.py --sensitivity`、`python 问题一_直接指派审计.py`、`python 问题一_直接指派绘图.py`；输入哈希、参数和环境见[本次复现清单](results/问题一_非枚举整数规划/复现清单.json)。原子集枚举版本可运行 `python 问题一_统一航段复现.py` 复核；旧几何口径的复现记录见[历史复现清单](results/历史结果_旧口径/复现清单.json)。

方法对比实验的复现命令：

```bash
python 问题一_方法对比.py
python 问题一_方法对比.py --scaling --sizes 15,17,19,21 --deadline 60
python 问题一_方法对比.py --full-lp
python 问题一_方法对比绘图.py
```

其中 `--full-lp` 需要约 3 分钟（未剪枝的集合覆盖 LP 在 S001 上要 194.6 s）；CSV 中的 `_耗时_s` 列为墙钟计时，随机器负载波动。
