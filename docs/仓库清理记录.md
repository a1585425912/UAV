## 四、如何恢复被移除的旧一代产物

旧一代产物由**确定性脚本**从原始数据生成，可原样重建：

```bash
# 在 UAV/ 目录下运行
python code/问题三四_复现.py
```

该入口依次执行 `问题三_候选中继点.py` → `问题三_求解.py` → `问题四_分区求解.py` → `问题三四_独立审计.py` → `问题三四_参考口径绘图.py`，并重写两份 `复现清单.json`，从而重建 `results/问题三_参考口径/` 与 `results/问题四_参考口径/`。

注意：

- 原命令 `--skip-site-search` 复用 `results/问题三_参考口径/候选悬停点覆盖.csv`，该文件已随清理移除，因此**首次重建不能加该开关**；重建一次后方可继续使用。
- 前置输入需齐备：`数据/无人机应急物资运输基础数据/*.xlsx`、`数据/镇龙乡及周边30米DEM.tif`、`results/航路节点坐标与作业高度.csv`、`results/有向航段几何参数.csv`、`results/问题二_参考口径/结果提交_主方案.xlsx`。
- 重建会恢复同名文件，但**当前保留的最新第三/四问成果不在恢复范围内**（它们是另一代产物）：`code/问题三_改进求解/`（4 中继窗口优化，联合完成 8914.079577 s）与 `results/问题四_改进求解/`（K=2 缺口 1 / 配置 25 / CV 0.843426；K=3 缺口 2 / 配置 26 / CV 1.176508），后者输入的 `plan_windows_opt.json` 指纹记录在 `results/问题四_改进求解/输入指纹.json`。
