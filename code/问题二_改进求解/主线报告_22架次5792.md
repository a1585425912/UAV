## 2. 新方法（本轮关键）

1. **路线池 + 受限集合划分 + 局部分支**（`q2_spp_minT.py`）：
   - 变量 `z_r∈{0,1}`，覆盖 `Σ_{r∋b} z_r = 1`；
   - 架次数上限 `Σ z_r ≤ N_target`；
   - 逐机型工时上界 `Σ_{r∈g} d_r z_r ≤ n_g Z`，目标 `min Z`；
   - 有效时限必要条件：对每个机型、每个完成期限 `D_r=LS_r+d_r`，`Σ_{D_r≤t} d_r z_r ≤ n_g t`；
   - **局部分支** `Σ_{r∈S_incumbent} z_r ≥ |S_incumbent| − k`（最多改动 k 条现有路线），使 MILP 围绕现有解、规模可控；
   - 选出后做时限感知排程，真实不可行只加 no-good 割/丢弃，不记为不可行。
2. **逐机型精确 MILP 排程**（`q2_exact_sched.py`）：对某机型所有架次，精确分配实体无人机、共享电池、顺序与开始时刻，含两阶段充电占用，并加入每架次最晚开始 LS 约束。对 22 架次方案的 C 型取得与现方案一致的最优值（5792.101 s），确认其排程已最优。
3. **关键改进链**：
   - 23 架次：5903.038 s（单箱迁移，见 `主线报告_23架次5903.md`）；
   - 22 架次：SPP+局部分支 k=8→10，把 B 型从 7 条降为 6 条、C 型保持 6 条，Z 从 6091.5 降到 5713.2；
   - 21 架次：最好 6485.937 s（B 型时限+资源约束下的精确最优即 6485.937 s，见下节）。

## 4. 21 架次为什么停在 6486 s

21 架次方案的 B 型 7 个任务：
- 忽略电池/时限的最优二划分 = **6200.569 s**；
- 加入 LS（硬时限+零延误）后的精确 MILP 最优 = **6485.937 s**；
- 二者相差 285.4 s，**是时限与共享电池周转造成的真实损失**，不是排程器不足。
所以在当前组批下，21 架次无法压到 ≤6300 s；要突破必须改变 B/C 的组批结构。
