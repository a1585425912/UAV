# 问题四改进求解说明

## 两类结果

- `K2_缺口优先.json` 与 `K3_缺口优先.json` 是按题面主目标得到的正式结果；
- `分组规模约束方案.json/.csv` 是对“不希望某组只有一个服务区”这一管理需求的政策备选。

原正式解出现单服务区组，不是枚举错误，而是“先最小化资源缺口”会将某些独立单元拆出。
`q4_policy_frontier.py` 在保留“同一运输架次涉及区域不可拆分”约束的同时，
穷举增加“每组至少 2 或 3 个服务区”的全部合法分区。

## 推荐的无单点备选

| 组数 | 每组最少服务区 | 缺口总数 | 配置总数 | 工作量 CV |
|---:|---:|---:|---:|---:|
| 2 | 2 | 3 | 31 | 0.845584 |
| 3 | 2 | 6 | 36 | 1.101943 |

它们比不限制组规模的正式缺口优先解分别多 1 和 2 个资源缺口，
是“管理可接受性”换取“额外资源”的显式权衡，不应与纯粋缺口最优解混为一谈。

python q4_policy_frontier.py
python q4_independent_check.py
