# 问题二、三中文论文图重绘说明

## 口径与用途

本轮只重绘图表，不改变任何求解结果。问题二采用 `results/问题二_改进方案/` 的四个改进方案，其中时间优先是该目录主方案。问题三只采用 `results/问题三_参考口径/` 的已发布主方案：22 条运输架次、4 条中继架次、80 箱交付、250 段通信保障。所有时间轴均以任务开始为零点，并明确标为小时或分钟。地图以站点间直线表示访问顺序，是示意连线，不代表 DEM 上的真实航迹。机型 A/B/C 同时用实线/虚线/点线区分，便于灰度打印。

| 图组 | 核心结论 | 证据与图型 |
|---|---|---|
| Q2 四张路线图 | 四种目标偏好对应不同访问顺序与机型分配 | 逐架次表；同范围 DEM 底图与机型色编码 |
| Q2 权衡图 | 更短完成时间对应较高能耗与更多架次 | 四方案原始点；时间—能耗散点，直接标架次数 |
| Q2 无人机、电池图 | 主方案的 24 架次按实体机和电池安排 | 逐架次时间区间；甘特图 |
| Q2 硬时限图 | 31 箱硬时限物资全部按时送达 | 逐箱交付；每箱一行的余量点图 |
| Q3 两张位置图 | 3 个静态中继点支撑 4 条中继架次及 22 条运输路线 | 发布的运输与中继表；DEM 底图 |
| Q3 交付图 | 80 箱在 15 个服务区的实际交付时刻 | 发布的逐箱交付表；逐箱点图，同刻交付会重叠 |
| Q3 通信图 | 运输架次需通信时段由直连或中继保障 | 发布的 250 段通信保障表；分段时间图 |
| Q3 窗口图 | 4 条中继架次的建链完成至服务结束窗口 | 发布的中继架次表；时间区间图 |

问题三旧版 `中继窗口权重分析.csv` 中标为“4中继-已发布”的行给出 1.068 s 缺口，与已发布完整方案的 0 s 缺口不一致；旧版还并列了待独立验证的三中继候选。本轮按用户选择的已发布主方案作图，不将该表或候选数值用于正式图。旧版服务区汇总表把关联架次的全程通信时长重复归入多个服务区，本轮交付图直接读取逐箱交付表，通信图直接读取发布的通信保障表。

## 复现与文件

从 `UAV` 目录运行：

```powershell
python 问题二_改进求解/redraw_paper_figures.py
python 问题三_成果呈现/redraw_paper_figures.py
```

正式图位于 `figures/问题二_论文重绘/`（8 张）与 `figures/问题三_论文重绘/`（5 张），每张同时有 320 DPI PNG 和保留可编辑文字的 SVG。灰度预览位于各目录的 `_qa/`。地图 SVG 嵌入 DEM 山体阴影位图，图上的文字、线段与符号仍保持矢量或可编辑文字；这是地形底图所需的例外。

原目录中的旧图和原绘图脚本保留，便于核对差异。论文引用图时，应引用本轮 `论文重绘` 目录中的文件。
